# うちのこギャラリー — Pages CMS 対応版

今のデザイン・キャラ紹介・タイル表示・タグ絞り込み・連作閲覧を維持した、GitHub Pages 用のサイトです。
公開ページには編集ボタンも保存APIもありません。編集は Pages CMS で行います。

## 最初の公開手順

1. このZIPを展開します。
2. GitHubで空のリポジトリを作ります。無料プランでGitHub Pagesを使う場合は公開リポジトリにします。
3. 展開したフォルダーの**中身**をリポジトリ直下にアップロードします。`.pages.yml` と `.github/workflows/pages.yml` も必ず含めてください。`gali-gallery-pagescms` という外側のフォルダーは入れません。
4. ブランチ名を `main` にします。
5. GitHubのリポジトリで **Settings → Pages → Build and deployment → Source → GitHub Actions** を選びます。
6. **Actions → Publish gallery → Run workflow** を実行します。完了するとPagesのURLで閲覧できます。以降は `main` への保存ごとに自動更新されます。
7. https://app.pagescms.org/ にGitHubでログインし、対象のリポジトリだけをPages CMSに許可して、`main` を開きます。ルートの `.pages.yml` を自動で読み取ります。

GitHubのリポジトリ作成、Pages CMSへのアカウント連携、実際のGitHub Pages公開は、このZIPを作成した段階ではまだ行っていません。
リポジトリへ置くものは公開したい文章・画像だけにしてください。

## 管理画面での編集

メニューは3つの世界ごとに分かれています。

- **世界観・キャラ**：ページ名、世界観説明、タブ画像、バナー画像、キャラ一覧を編集します。
- **ギャラリー**：投稿を新規作成・編集・削除します。

### キャラクター

「キャラクター一覧」で項目を追加します。名前、説明、背景の英字名、一覧用のサムネイル、メイン立ち絵、設定画を登録できます。
メイン立ち絵は詳細画面右側、設定画は下部の3列サムネイルになります。サムネイルを省略すると立ち絵を使います。
キャラ一覧と設定画はリストの順番が表示順です。
管理用IDは自動生成されるため変更しません。

### 画像・連作・漫画

1. 該当する「ギャラリー」で新規投稿を作ります。
2. タイトルと説明を入力し、画像欄に画像を追加します。
3. 画像が1枚なら単独画像、2枚以上なら連作として自動表示します。**先頭が表紙、リストの順番が読む順番**です。
4. タグは項目を追加して1つずつ入力します。
5. 「公開する」をオンにして保存します。オフの投稿はサイトに出ません。
6. 保存するとGitHubに変更が入り、Actionsがサイトを更新します。更新完了まで少し時間がかかります。

「表示順」は小さい数字ほど上です。既存投稿は10、20、30…に設定しています。新規投稿の初期値0は先頭側になります。複数の新規投稿の順番を決めたい場合は異なる数字を指定してください。
上部PREV/NEXTは現在のタグに一致する**投稿間**の移動、下部は**連作内**のページ送りです。

## 手動調整するファイル

| 目的 | ファイル |
| --- | --- |
| 基本の色 | `assets/theme.css` |
| 余白・文字サイズ・レイアウト | `assets/layout.css` |
| 表示や操作の仕組み | `assets/app.js` |
| 管理画面の項目 | `.pages.yml` |
| 世界観・キャラの文章 | `content/worlds/0.json` ～ `2.json` |
| ギャラリーの投稿 | `content/gallery/0/` ～ `2/` |
| アップロード画像 | `media/` |

`assets/theme.css` は最後に読み込まれます。基本の色はここで上書きできます。部分ごとの固定色を変える場合も、このファイル末尾に指定を追加できます。

## 自分のPCで確認する場合

Node.js 22以上があれば、展開先で次を実行します（追加パッケージのインストールは不要）。

```sh
npm run build
npm run dev
```

表示されたローカルURLを開きます。ファイルを変更したらもう一度ビルドしてページを再読み込みします。
HTMLファイルを直接ダブルクリックした場合は、ブラウザの制約でデータを読み込めません。

## 技術メモ

- `.pages.yml` でPages CMSの編集項目を定義しています。
- `scripts/build.mjs` が個別のJSON投稿を集めて `dist/data/gallery.json` を生成します。
- `dist/` に公開用のHTML・CSS・JavaScript・画像をまとめます。
- `.github/workflows/pages.yml` が `main` の変更時にビルドしてGitHub Pagesへ公開します。
- 画像は相対パスに変換するため、`ユーザー.github.io/リポジトリ名/` と独自ドメインの両方に対応します。
- 公開成果物にはCMS設定・編集用JSONファイル・GitHubの認証情報は入りません。ただし公開表示用の文章と画像は公開データです。公開リポジトリではソースも閲覧できます。
- Pages CMSのアカウントや認証は公式サービス側で扱い、このサイトにはトークン等を保存しません。
- 既存の試作品から世界観3件・キャラ1人・投稿8件と、それらが参照する画像を移行しました。参照画像は重複をまとめて16ファイルです。
- この移行後に元の試作品へ加えた編集は、自動では同期されません。
